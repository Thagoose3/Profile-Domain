# 🪿🌾 Thagoose - Farm & Goose Portfolio Hub

เว็บไซต์โปรไฟล์ส่วนตัวและศูนย์รวมเว็บแอปพลิเคชัน (Portfolio & App Hub) สไตล์ **Modern Farm & Goose Theme 🪿🌾** พัฒนาขึ้นสำหรับโฮสต์บน GitHub Pages

🌐 **Live URL**: [https://thagoose3.github.io/Profile-Domain/](https://thagoose3.github.io/Profile-Domain/)

---

## 🎨 จุดเด่นของดีไซน์ (Design & Features)

- 🌾 **Illustrated Farm & Geese Background**: ภาพพื้นหลังฟาร์มห่านและทุ่งหญ้า พร้อมโหมดกลางคืน (Starry Night & Fireflies) สบายตา ไม่บดบังตัวอักษร
- 📦 **Compact & Scaled Preview Cards**: การ์ดแสดงพรีวิวผลงานขนาดกะทัดรัด (สูง 140px) ไม่ใหญ่เกินหน้าจอ แสดงผลกราฟิกชัดเจน
- 🚀 **Featured Web Apps**:
  - 💰 **[Money Memo](https://thagoose3.github.io/Money-memo)**: เว็บแอปบันทึกรายรับ-รายจ่ายอัจฉริยะ พร้อมแดชบอร์ดสรุปยอด
  - 🏋️ **[Exercise Tracker](https://thagoose3.github.io/Exercise)**: แอปพลิเคชันบันทึกตารางการออกกำลังกายและ Routine
  - 🥗 **[Calories Tracker](https://thagoose3.github.io/Calories_Tracker)**: ระบบคำนวณและติดตามโภชนาการ แคลอรี่ และสารอาหารหลัก
- ⚡ **Live GitHub Repos Sync**: ดึงข้อมูลคลัง Repository สดจากบัญชี `@Thagoose3` อัตโนมัติ พร้อมปุ่มเปิดเว็บแอปและดูโค้ด
- 🌓 **Day & Night Farm Theme**: สลับธีมสว่าง (ทุ่งหญ้าแสงแดดอบอุ่น) / ธีมมืด (ฟาร์มใต้แสงจันทร์และหิ่งห้อย)
- 🔊 **"Honk!" Easter Egg**: กดที่รูป Mascot หรือปุ่ม Honk เพื่อฟังเสียงร้องเจ้าห่านสังเคราะห์ผ่าน Web Audio API
- 📱 **Mobile & Desktop Friendly**: ออกแบบด้วยสไตล์ Responsive Grid เปิดดูได้อย่างสวยงามบนทุกหน้าจอ

## 🚀 การจัดการและ Push ผ่าน GitHub Desktop

1. เปิดโปรแกรม **GitHub Desktop**
2. เลือก Repository **`Profile-Domain`**
3. คุณจะเห็นการเปลี่ยนแปลงและ Commit ใหม่ที่เตรียมไว้
4. คลิกปุ่ม **Push origin** ที่มุมขวาบน เพื่อนำโค้ดขึ้นหน้าเว็บจริงได้ทันทีครับ
